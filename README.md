# Бот записи на семинары

Следит за Google-таблицей записи (формат как в таблице «Философия»). Когда появляется
свободное место — новый блок «N семинар», новая колонка или освободившаяся клетка
в строке «… вопрос» — бот вписывает туда твоё имя/инициалы. В каждый семинар
записывает **один раз**: если ты там уже есть, этот семинар пропускается.

## ⚠️ Важно: нужны права на редактирование

Бот пишет в таблицу от имени Google-аккаунта. Если у тебя таблица открыта в режиме
**View only**, бот тоже не сможет писать. Нужен доступ «Редактор»: либо для твоего
аккаунта, либо для сервисного аккаунта (попроси владельца таблицы его добавить).

## Установка

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json   # и отредактируй
```

## Доступ к Google Sheets API

1. Зайди в <https://console.cloud.google.com/>, создай проект.
2. «APIs & Services» → «Enable APIs» → включи **Google Sheets API** и **Google Drive API**.
3. Дальше один из вариантов:
   - **Свой аккаунт (`"auth": "oauth"`)** — «Credentials» → «Create credentials» →
     «OAuth client ID» → тип «Desktop app». Скачай JSON и положи рядом с ботом как
     `credentials.json`. Если попросит настроить OAuth consent screen — тип «External»,
     добавь свою почту в «Test users». При первом запуске откроется браузер для входа.
   - **Сервисный аккаунт (`"auth": "service_account"`)** — «Create credentials» →
     «Service account» → «Keys» → «Add key» → JSON, сохрани как `service_account.json`.
     Почту сервисного аккаунта (`...@...iam.gserviceaccount.com`) владелец таблицы
     должен добавить как редактора.

## Настройки `config.json`

| Поле | Что это |
|---|---|
| `spreadsheet` | ссылка на таблицу или её ID |
| `worksheet` | название листа (`"Лист1"`), `null` — первый лист |
| `name` | что вписать, например `"Иванов И.И."` |
| `aliases` | как ещё тебя могут записать (фамилия маленькими буквами и т.п.) — чтобы бот понял, что ты уже записан |
| `row_label_pattern` | какие строки считать местами для записи (regex по колонке A), по умолчанию `"вопрос"`; «Индивидуальное задание» не трогается |
| `only_new_seminars` | `true` — не трогать семинары, которые уже были в таблице при запуске, записываться только в новые |
| `skip_seminars` | номера семинаров, в которые не записываться, например `[1, 2]` |
| `poll_seconds` | как часто проверять таблицу (не делай меньше ~5 с — у Google лимит 60 запросов в минуту) |

## Запуск

```bash
python bot.py --dry-run --once   # проверить: покажет, куда записал бы, ничего не меняя
python bot.py                    # следить постоянно (Ctrl+C — остановить)
```

Бот должен быть запущен, чтобы ловить новые места: оставь его в терминале, на
сервере (`nohup python bot.py &`, `tmux`, systemd) или на любом VPS.

Место выбирается первое свободное: сначала «1 вопрос» слева направо, потом «2 вопрос»
и т.д. Перед записью клетка перепроверяется, а после — проверяется, что твою запись
никто не перезатёр.
